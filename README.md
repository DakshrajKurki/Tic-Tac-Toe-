# ❌⭕ Tic-Tac-Toe (Python)

A two-player Tic-Tac-Toe game that runs in the terminal / a Jupyter notebook.

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)
![Jupyter](https://img.shields.io/badge/Jupyter-F37626?style=flat-square&logo=jupyter&logoColor=white)

## Features

- Draws a 3×3 board after every move
- Players choose X or O and take turns entering a position
- Validates moves (no overwriting a filled square)
- Detects wins across rows, columns and diagonals, and detects a draw

## Run it

```bash
jupyter notebook "Tic Tac Toe.ipynb"
```
Run all cells and follow the prompts.

## What I practised

Functions, 2-D lists, loops, input validation and game-state checking.
